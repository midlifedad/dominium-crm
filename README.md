# Dominium CRM - Twilio SMS Consent Portal

Hosted opt-in/opt-out page for toll-free verification compliance.

## Features

- Public URL where users enter phone number
- Twilio Verify sends OTP code
- After verification shows consent status
- Opt-in/opt-out buttons with confirmation SMS
- Integrates with Twilio Consent Management API
- Audit logging for compliance

## Deployment
